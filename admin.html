IMPORTANTE: Después de procesar, descarga LOYMAR_FOTOS_ACTUALIZADAS.zip y descomprímelo sobre la carpeta del catálogo donde está index.html. Cuando Windows pregunte, elige Reemplazar para data/catalog.js, data/catalog.json y combina la carpeta productos. Esta es la actualización que hace que las fotos aparezcan en el catálogo.
Cómo funciona: las coincidencias automáticas ahora son estrictas y seguras: solo se acepta un código interno o de barras cuando aparece de forma inequívoca en el nombre del archivo (por ejemplo 835.jpg, 835_motosierra.jpg o COD-835.jpg). Nombres como IMG_4987.jpg, fechas o números de cámara no se usan para vincular automáticamente. Los demás casos se asignan manualmente. Puedes cambiar o desvincular cualquier asociación antes de procesar.
